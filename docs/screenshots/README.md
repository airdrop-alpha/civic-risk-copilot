## Capture guidance

### 1. Dashboard overview
Make sure the shot includes:
- risk gauge
- hero stats
- at least 4 factor cards
- Action Brief
- recent timestamp

### 2. Source reliability
Make sure the shot includes:
- Source Reliability card
- at least one non-live source state if available
- any graceful degradation banner or status message

### 3. AI copilot
Make sure the shot includes:
- user prompt
- grounded answer
- clear Montgomery-specific context

### 4. Demo mode
Make sure the shot includes:
- severe or high-risk score
- critical banner
- visibly elevated factors
- action-oriented summary
